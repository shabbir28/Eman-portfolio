Ruya Realty

A cross-platform real estate app prototype built with React Native and Expo, exploring welcome, onboarding and account flows.

Project

Cross-platform mobile application

Status

UI prototype · In development

The project

A place to begin.

Ruya Realty explores the first steps of a mobile real estate experience: introducing the brand, helping people discover the idea of finding a home, and presenting account entry screens. Navy tones, architectural photography and rounded panels give the interface a calm, welcoming feel.

This is an early UI-focused project. The broader vision is to help people browse, buy and rent homes, apartments and studios. Property search, listing management and transactions are not complete in the current source.

What's in the prototype

  • Welcome screen: Architectural photography with a curved navy brand panel.
  • Two onboarding steps: Introductions to finding a home and listing a property, with next and skip navigation.
  • Account screens: Entry, login, signup and password recovery interfaces.
  • Responsive layouts: Percentage-based sizing and consistent visual patterns across mobile screens.

How it's built

React Native components and JavaScript define the screens, Expo provides the application setup, and Expo Router organizes navigation. The source includes an initial login API integration, but the complete account and property experience is unfinished. The homepage currently repeats an onboarding screen.

Built with
