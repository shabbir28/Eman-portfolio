DHA STORE INVENTORY — PORTFOLIO DEMO
By Eman Abdul Malik

Windows x64. Extract the entire ZIP, then open DHAInventoryDemo.exe.
Keep the app and runtime folders beside the EXE. No Java or MySQL installation needed.

Username: demo
Password: demo123

Try Dashboard, Add Item, Assign Item, Return Item, Store Inventory, User Inventory,
Auction Inventory, Report, Low Stock and DHA Employee.
All employees, suppliers, references and inventory records are fictional.
Changes reset after closing all demo windows and restarting the application.
The demo uses an H2 in-memory database. Network synchronization and production
database configuration are disabled.

Adapted from the source archive supplied by the project author. Original JavaFX
screens retained. Demo fixes include string employee IDs, initial dashboard loading,
resize anchors, receipt/issue/return balance calculations and embedded database support.

Bundled dependencies: Java 21 runtime, JavaFX 21, JFoenix 8.0.5, FontAwesomeFX 8.9,
H2 2.3.232. Runtime notices are retained under runtime/legal. Dependency license
notices are retained inside the respective JARs (META-INF).
