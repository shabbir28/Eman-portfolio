The project

A closer look.

The Mandarin Inn Inventory Management System brings hotel stock records into one Java desktop application. Staff can organize supplies across furniture, electronics, miscellaneous items, cleaning supplies, kitchen items, and laundry, with room-level tracking available for supported categories.

After login, a visual category menu leads to dedicated inventory screens for updating quantities, searching records, and reviewing tables of stock data. A room lookup brings furniture, electronics, and miscellaneous inventory together for a selected room, helping make routine checks and updates more structured.

Inventory workflows

  • Six inventory categories: Separate screens organize furniture, electronics, miscellaneous supplies, cleaning supplies, kitchen items, and laundry.
  • Quantity updates: Category forms support adding and removing stock and maintaining item records.
  • Room-based tracking: Supported categories associate quantities with rooms, with a combined room view for furniture, electronics, and miscellaneous items.
  • Search and summaries: Search controls and data tables help staff review matching records and category totals.

Interface and implementation

The interface uses Java Swing layouts, custom rounded controls, and category illustrations with a dark-green and warm-neutral palette. The application connects to MySQL through JDBC, using database queries to load room and item data and persist inventory updates.
