The project

A closer look.

The DHA Store Inventory System is a Java desktop application prototype for recording and reviewing organizational equipment across store, employee, and auction inventory workflows. It brings incoming stock, quantities, recipients, and issue details into a structured application backed by MySQL.

A JavaFX workspace organizes the experience around a dashboard, item intake, assignment forms, and inventory-related screens. Receiving is separated into store, user, and auction workflows so each can capture the details it needs—for example, purchase source, employee and warranty information, or auction letter details.

Inventory workflows

  • Three receipt paths: Record store purchases, employee-related items, and auction receipts with workflow-specific details.
  • Item assignments: Dedicated forms capture store, user, and auction assignment information.
  • Inventory dashboard: Store, user, and auction views present summary metrics and low-stock information.
  • Structured inventory data: MySQL tables represent receipts, stock balances, recipients, branches, issue statuses, and returns.

Technical implementation

The application is organized into JavaFX/FXML views, controllers, services, repositories, and domain models. JDBC repositories use prepared statements for database operations, while the MySQL schema uses foreign keys, triggers, and aggregation queries to support inventory records and dashboard metrics.

  • Java 21
  • JavaFX
  • FXML
  • Maven
  • JDBC
  • MySQL

Prototype status

This is a functional prototype, and some screens still need integration and verification. Assignment persistence, return handling, inventory listings, and reporting require further work before the system is ready for production use. The downloadable Windows demo runs with sample data and does not connect to a live store database.
