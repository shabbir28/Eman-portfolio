MANDARIN INVENTORY - PORTFOLIO DEMO
By Eman Abdul Malik

Windows x64. Extract the entire ZIP, then open MandarinInventoryDemo.exe.
Keep the app and runtime folders beside the EXE. No Java or MySQL installation needed.

Username: demo
Password: demo123

Try Furniture > Total Data, search by room/item, or add and remove quantities.
Explore Electronics, Miscellaneous, Clean, Kitchen, Laundry and Room Inventory.
All records are fictional. Changes reset when you close all app windows and reopen.
This demo does not connect to the hotel's database.

The production application uses Java Swing and MySQL and is used by The Mandarin Inn,
Gilgit-Baltistan. This demonstration edition preserves the Swing screens and uses an
embedded H2 in-memory database for a standalone experience.
